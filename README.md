# AllClip（kb-clipper）

Chrome 插件：把网上看到的内容抓成干净的 Markdown，连同图片一起存进 Obsidian 的 `AllClip/` 文件夹。

- 设计文档：[docs/design.md](docs/design.md)
- 开源方案调研：[docs/research.md](docs/research.md)

## 当前进度

| 期 | 内容 | 状态 |
|---|---|---|
| M0 | 骨架：弹窗、设置页、快捷键、右键菜单、Obsidian 写入（REST / URI）、图片本地化、去重更新、通用网页 | ✅ |
| M1 | X / 推特：单条、线程、引用、长推文、X Article 长文、投票、原图、视频（可选下载）、右键保存时间线上的推文 | ✅ |
| M2 | 小红书：图文（多图、实况图）、视频（可选下载）、话题标签、互动数据、评论（可勾选） | ✅ |
| M3 | 知乎：回答、专栏文章、想法；公式、脚注、原图、链接卡片、代码；问题页存屏幕中间那条 | ✅ |
| M4 | Reddit：文字/图片/图集/视频/外链/转发帖，得分最高的评论（默认 10 条，带回复） | ✅ |
| M5 | 页内“收录”按钮（推特、小红书）、右键识别鼠标所在内容、只存选中文字（摘录笔记）、文件名模板 / status / 默认标签、注入脚本瘦身 | ✅ |

推特、小红书、知乎、Reddit 走专门的适配器，其它网页走通用模式（Defuddle 提取正文）。

**注意**：插件装好或更新后，已经打开的推特、小红书、知乎、Reddit 标签页要刷新一次，才能拿到完整数据（长推文、线程、视频）。没刷新也能存，但只能读页面上的文字，弹窗里会提示。

**小红书注意**：图片和视频链接带签名、会过期，建议用 Local REST API 方式，图片当场存到本地；用 obsidian:// 方式保存的图片过一段时间会打不开。

## 安装（开发版）

```bash
pnpm install
pnpm build
```

1. 打开 `chrome://extensions`，打开右上角“开发者模式”。
2. 点“加载已解压的扩展程序”，选 `.output/chrome-mv3` 文件夹。
3. 第一次安装会自动打开设置页，按提示连接 Obsidian。

开发时用 `pnpm dev`，会打开一个装好插件的 Chrome，改代码自动重载。

## 连接 Obsidian

**Local REST API（推荐，图片存本地）**

1. Obsidian → 设置 → 第三方插件 → 浏览，搜索 **Local REST API**，安装并启用。
2. 插件设置里打开 **Enable Non-encrypted (HTTP) Server**（端口 27123）。
3. 复制 API Key，粘贴到插件设置页，点“测试连接”。

**obsidian:// 链接（零配置）**：设置页选这个方式，填仓库名即可。图片保留网络链接。

## 使用

| 操作 | 效果 |
|---|---|
| `⌥S` | 直接保存当前页，右下角提示结果 |
| `⌥⇧S` 或点工具栏图标 | 打开弹窗，可改标题、加标签、写备注 |
| 弹窗里 `⌘↵` | 保存 |
| 右键 → 保存到 AllClip | 同 `⌥S`；在推特/知乎/Reddit 的某一条上右键，存的就是那一条 |
| 推文、小红书笔记旁的收录按钮 | 点一下直接存这一条（设置里可关） |
| 先选中一段文字再打开弹窗 | 可以只存选中的部分，存成单独的「（摘录）」笔记 |

各平台“存哪一条”的规则：

| 平台 | 规则 |
|---|---|
| 推特 | 右键/按钮所在的推文 > 地址栏里的推文；线程自动合并 |
| 小红书 | 当前打开的笔记（浮层或详情页） |
| 知乎 | 右键所在的回答 > 地址里的回答 > 屏幕中间那条 |
| Reddit | 右键所在的帖子 > 地址里的帖子 > 屏幕中间那条 |

同一篇内容再次保存会**更新原笔记**，正文刷新，`## 我的备注` 下面写的东西保留。

## 开发

```bash
pnpm test       # 单元测试（渲染、文件名、REST 写入、推特和小红书转换，样本在 tests/fixtures）
pnpm compile    # 类型检查
pnpm build && ./dev/harness.sh   # 生成界面预览页 .output/preview（模拟 chrome API）
```

`dev/` 下的 `*-probe.ts` 是开发时注入真实页面验证适配器用的，不会打包进插件。

## 已知限制

- **Reddit 没有用真实数据验证过**：开发环境里 Reddit 拦截了脚本请求，样本是按官方 JSON 格式手写的。插件在你的浏览器里用你自己的会话请求，正常情况下能拿到；拿不到时会退回读页面。
- **小红书**：只测了未登录时“直接打开笔记链接”的情况；登录后在信息流里点开浮层，按设计也走同一份页面数据。
- **知乎评论**不存（需要调接口）；**Reddit 视频**音画分离，只存封面和链接。
- obsidian:// 方式存不了本地图片，小红书的图片链接过段时间会失效。
